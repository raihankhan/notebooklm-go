### Acceptance criteria
- [ ] `cassette.NewRecorder(t, name)` returns a `*recorder.Recorder` with the ported matcher.
- [ ] Matcher fields: method, scheme, host, port, path, rpcids (URL query), freq (decoded f.req form body).
- [ ] `AfterCaptureHook` rewrites Cookie, SNlM0e, FdrFJe, at=, f.sid, emails, signed URL params.
- [ ] `scrubhar` CLI: `go run ./internal/tools/scrubhar path/to/cassette.yaml` rewrites a file in place, idempotent.
- [ ] Pre-commit guard test walks every committed cassette and fails on credential regex match.
- [ ] `TestMatchTuplePinned`: a test that asserts the matcher rejects mismatches on each field.
- [ ] `make test-cassette` target wired.

### Tests
- `TestScrubHarIdempotent`: scrub a cassette twice, byte-identical output.
- `TestScrubHarRemovesAllCredentials`: feed a cassette with embedded credentials, assert none survive.
- `TestMatchTuplePinned`: each field mismatch produces a non-match.
- `TestNoCredentialInCassettes`: walks testdata/cassettes/, asserts clean.

### Risk
high — a credential leak in a cassette is a security incident.
